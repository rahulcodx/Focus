## File Requirements:

- Format: WAV (uncompressed audio)
- Sample Rate: Any standard sample rate (44.1kHz recommended)
- Duration: Any length (will be automatically looped)
- Quality: Clean, ambient sound without music or speech

## Usage:

- **Sound Effects**: Use the sound icon in bottom navigation to access ambient sounds
- **Music**: Use the music icon to access the Spotify lofi playlist
- **Both**: Can be used simultaneously for the perfect study/relaxation environment
